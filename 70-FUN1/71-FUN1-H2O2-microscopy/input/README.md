## 2026-04-03, data from 2022-12-12

Raw microscopy image data (in `.lif` format) can be found on RDSS/User/archive/Hanxi/microscopy in a folder with the same date. The `.ome.tiff` files were the original image preserving all meta info and bit-depth, exported from FIJI, which was used to load the original `.lif` file. In the `output` folder, a series of `.png` files are flattened images after contrast adjustment and adding the scale bar. Contrast was adjusted in identical ways for all 6 images (90-255 for the red channle; 110-255 for the Bright Field channel).
